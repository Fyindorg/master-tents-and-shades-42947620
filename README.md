# Master Tents Replica

Rebuild Master Tents & Shades Website — Exact Visual & Content Migration

I need you to completely rebuild the existing website:

https://mastertentsandshades.com/

The current website is built using WordPress. The site has previously experienced a security/hacking incident, and I now want to completely move away from WordPress.

Your task is to recreate the existing website as a modern, production-ready web application using Lovable.

MOST IMPORTANT REQUIREMENT

DO NOT redesign, modernize, improve, simplify, reinterpret, or change the visual design of the existing website.

The new website must look and behave as close as technically possible to the current website.

Think of this as:

"Rebuild the existing website using a new technology stack, without changing the website."

NOT:

"Create a better/new website for Master Tents & Shades."

Visual fidelity takes priority over design improvements.
